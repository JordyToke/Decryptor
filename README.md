## Summary

This is a small web-app for encrypting and decrypting basic cipher's.

I originally made the app to help me solve encoded messages I was given as a player in a TTRPG.

## How to use

To run the Cipher Encryptor/Decryptor simply download the project folder and open the `index.html` in your browser.

## Features


Caesar cipher
>  - [x] basic caesar cipher function
>  - [x] adjustable rotation
>  - [x] adjustable steps
>
Web User Interface
>  - [x] Text entry field
>  - [x] Cipher Selection
>  - [x] Cipher Parameters
>  - [x] auto-encryption
>  - [x] output area
>
Extra features:
>Support for aditional ciphers
>  - [ ] playfair
>  - [ ] atbash
>  - [ ] vigenére
